Ludo Online - deploy (no environment variables needed)

Render.com (free):
 1. Put this folder on GitHub (upload the files, keep server.js + package.json at the repo root).
 2. Render -> New -> Web Service -> pick the repo.
 3. Build command: npm install     Start command: npm start
 4. Deploy. Open the https://....onrender.com link, create a room, share the code.

Local: npm install && npm start  ->  http://localhost:3000
